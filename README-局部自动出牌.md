# 局部自动出牌 v0.5.8

单人战斗中，左侧有两个操作：

- **自动一回合**：参考当前及后续两个回合规划出牌，必要时提前结束回合；只执行当前回合，不会接管下一回合。
- **全自动**：逐回合出牌并结束回合；开关状态保存在 `user://local_auto_play_settings.json`，下场战斗及重启游戏后继续生效，直至手动关闭。不会自动走地图、选择奖励或使用药水。

正在执行时点击「停止本回合」，会在当前牌结算后停止。全自动按钮可随时关闭。出现未知的选牌界面或游戏自身无法继续结算时，会暂停而不会强行结束回合。

v0.5.8 针对手机录像中的停顿减少重复搜索：单次当前回合搜索上限 170 毫秒、三回合总上限 420 毫秒；完整计划中的下一张牌只在手牌、费用、能量、敌我血量与格挡、充能球、能力和遗物记录均与预测吻合时直接执行，否则立即重新规划。日志增加 `captureMs`、`totalMs`、`CACHE_HIT` 与 `CACHE_INVALIDATED`，便于量化性能。当前回合立即斩杀仍然最高优先级；后两回合的假设斩杀不再得到同等确定的高分，且降低了未来不确定回合的权重。完全等价的路线会轻微偏向保留更多能量。录像中「模组改造」打出前显示 0 费，打出动画中恢复 1 费，属于打出后临时费用到期，并非先打其他牌导致的涨费。

## 规划与本次修复

模组读取已知抽牌顺序，并复制洗牌、产牌和随机充能球 RNG；预测不会消耗游戏的真实随机数。每张牌真实结算后会校验实际状态。当前回合最多搜索 48 步、束宽 48、16,000 节点；后续两回合分别使用有界搜索，总规划时间上限 420 毫秒。不会执行预览中的游戏动作。

v0.5.0 把「结束回合」纳入候选，不再为了清空手牌而强制打出无收益的防御牌或能力牌。规划器对整条路线的回合终局状态评分：计入斩杀、敌人下一次攻击、格挡、充能球被动以及下回合的球与能力价值。现已模拟球的顺序、暗球蓄能与激发、部分改造版球牌、野性回手、散热片抽牌、「搜寻」从抽牌堆选牌和「涅奥之怒」从弃牌堆回收；规划的选牌会交给游戏原生选牌界面执行。

v0.5.1 排查并修正了其他牌的同类顺序问题：充能电池和拾荒等延迟回能不再被当作当前能量，分离仅击杀后回能；原版弹幕齐射按球数计算，X 费伤害和格挡按实际 X 计算。补上全息影像、快速检索、刮削、暴风雨、回收、堆栈、万物一心、编译驱动、重启、四重释放、打碎和数种产球牌对当前回合的影响。去重状态现在区分本回合出牌数，避免超越光速的抽牌条件被误合并。该版每次出牌后都会重新规划；v0.5.8 改为验证后复用计划。

v0.5.2 根据双战斗录像补充「高蓄能黑球 + 四重释放 + 电击」顺序回归测试；规划器应先打出可斩杀的四重释放。还会等待游戏动作队列完全结算，再读取手牌；若规划期间手牌、球或敌人状态变化则重新规划。当前无可选出牌但有疑似临时不可打的卡牌时，会短暂等待状态变化，而不是立即结束回合。结束回合前记录手牌可打状态，便于后续核查录像中的实际模组版本和原因。录像中使用的模组版本无法仅凭画面确定，本次修改尚未在该手机对局实测。

v0.5.3 把战斗状态纳入搜索：敌人的易伤、虚弱、人工制品、缓冲、无实体、荆棘及格挡会影响攻击收益和生存预估；我方现有力量、敏捷、活力、缓冲、无实体，以及本回合新获得的力量、敏捷、缓冲，会影响后续牌。钢笔尖、双节棍、手里剑、苦无、精致折扇和开信刀按当前计数预测下一次触发。卡牌预览已经包含的现有加成不会再次叠加；预览后发生的加成变化由搜索状态补足。规划中敌我能力或遗物计数发生变化时会重新取快照。新增遗物触发顺序、人工制品抵挡易伤、缓冲挡刀等离线回归测试。

v0.5.4 纳入卡牌附魔与临时状态：会按现有状态预测 Sown 首次回能、Swift 首次抽牌、Adroit 额外格挡、Inky 附加虚弱、Corrupted 自伤、Glam／Spiral 重复打出、Vigorous 一次性伤害、Momentum 逐次成长，以及 Slither 抽到时的随机费用。Sharp、Nimble 等直接改卡面数值的附魔沿用游戏实时预览，避免重复加成。会模拟下次打出即失效的费用、临时免费攻击／技能／能力消耗、Burst 与 Echo Form 的重复、Corruption 的免费技能和消耗，以及 Hotfix 等临时集中的回合末失效；临时力量／敏捷不会被当作永久成长。附魔状态、费用、能力变化会触发重新规划。PC 与手机目标程序集均通过同一组离线回归。

v0.5.5 将预测窗口扩展到三个玩家回合。每个回合边界会模拟手牌弃置、虚无牌消耗、保留牌、回合结束时的费用和临时能力清理、敌人已知攻击、下回合能量与抽牌、充能球在正确阶段的被动，以及循环。限时搜索会保留不同首张牌的候选路线，避免只为眼前伤害而错过后两回合的成长收益。未来敌方意图和敌人塞牌等行动无法从当前画面确定，后两回合仅采用风险估计；游戏进入下一回合后重新读取真实状态与意图。此处为三回合有界预测，不承诺穷举最优解。

v0.5.6 重新评估充能球的剩余价值，不再给每种球固定倍率。电球与玻璃球的余值受存活敌人数和剩余血量约束，玻璃球计入群伤及逐回合衰减；冰球按预计需要抵挡的伤害计分；黑球根据蓄能、可否抽到激发牌以及球位满时被挤出的机会估算兑现概率；等离子球依据下次可见手牌的能量缺口计分。即将挤出的最左侧球会额外计入部分激发价值，所有伤害余值合计不超过敌人剩余血量。电球被动与激发的目标改用复制的 `CombatTargets` 随机流预测，而非总是假设命中最低血量敌人；不会推进游戏真实随机数。后两回合的敌方意图及更远的洗牌仍属估计，以上余值也只用于有限预测的决策评分，不是卡牌或充能球的永久强度表。

v0.5.7 在 PC v0.107.1 的真实战斗桥中回归测试，修复原版「多重释放」在仅有一个球时只预测一次激发、因此错误空过的问题；现在按 X 次激发同一个球，仅最后一次移除。改造版仍按 BetterDefect 的队列右端球重复双重激发并重新生成。实战验证涵盖多重释放的实际伤害、优先击杀低血量攻击者、闪电球预测目标与实际目标一致，以及选牌、已知抽牌、回能铺垫和自动结束回合。三回合轨迹确实参与规划，但未来敌人意图仍是估计，尚未逐一对照所有能力、遗物和附魔的完整三回合战斗。

单回合最多实际打出 64 张牌，以阻止零费循环。其他尚未专门建模的遗物、能力、附魔及随机目标仍可能造成预测偏差；X 费牌的重复打出尚未模拟，缓冲对多段攻击和荆棘结算次序只做近似。每张牌结算后都会用游戏真实状态校验后续计划，不吻合就重算；束搜索也可能裁剪更好的顺序，因此这是限时近似最优，不保证数学意义上的全局最优。某张可打的牌如果不能改善局面，自动器可能选择留在手中并结束回合。默认不使用药水。

## 安装

把对应平台压缩包中的 `LocalAutoPlay` 文件夹放入游戏 `mods` 目录。PC v0.107.1 与手机 v0.111.0 的 DLL 分别编译，不可混用。无需 BaseLib 或 RitsuLib。
