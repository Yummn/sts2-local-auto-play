# 局部自动出牌 v0.2.0

在**单人战斗**中点左侧的「自动打牌」按钮，模组会从当前手牌选择一张游戏允许打出且局部评分较高的牌，使用游戏原生 `TryManualPlay` 入队；待结算完成后重新读取局面，再选择下一张。再次点击可在当前牌结算后停止。

- 不自动结束回合；药水默认关闭，目前也不提供自动使用药水的开关。
- 不再限制卡牌名单：所有游戏判断可打出的牌（包括自定义、X 费、状态牌）都参与选择。模组使用游戏原生出牌队列，不自己结算卡牌效果。
- 对通过 `CardSelectCmd` 请求的战斗选牌自动作出局部选择。其他模组独立实现的交互若不能由原生选择器处理，会在超时后暂停并交还玩家。
- 最多连续打出 24 张，以避免零费无限循环；回合改变、界面关闭、状态不一致或出牌超时会停止。
- 不依赖 BaseLib 或 RitsuLib。兼容性以各版本实测为准。
- 局部评分考虑斩杀、敌方当前意图、缺少的格挡、伤害、抽牌、能量与费用；未知卡牌效果给予兜底评分。**不是最优解计算器**，也不保证所有复杂牌的最佳选择。

安装：将 `LocalAutoPlay.dll` 和 `LocalAutoPlay.json` 放在同一个 `mods/LocalAutoPlay/` 文件夹。分别使用对应游戏版本编译的包，不要混用 DLL。
