# 局部自动出牌 v0.3.0

单人战斗中点左侧「自动打牌」，模组会在当前回合内反复选牌、使用游戏原生 `TryManualPlay` 出牌，并在每张牌真实结算后重新规划。再次点击会在当前牌结算后停止。

## 策略

- 不再限制卡牌名单；游戏判定当前可打出的牌均参与选择。仅因能量不足暂时打不出的牌也会进入后续步骤的规划，便于评估先回能再出高费牌。
- 使用最多 3 步、束宽 8 的轻量前瞻，预计伤害、击杀、来袭伤害、有效格挡、抽牌、回能和能力牌收益。先击杀敌人会减少预计来袭伤害，超额格挡只获很低评分。
- 每次只真正打出第一张牌；预测不执行游戏效果。结算后从真实局面重算，因此可兼容大量未建模的模组牌，但预测并非精确模拟。
- 可打出的状态/诅咒默认不自动使用；对其余未知效果保留低分兜底。原生选牌允许跳过时，会跳过明显不利的可选选择；强制选择仍按卡牌价值挑选。
- 单次点击最多 24 张，防止零费循环；仅当前回合有效。不自动使用药水，也不自动结束回合。

规划深度、展开数量和耗时均有上限，以降低手机帧率影响。模组独立实现的特殊选择界面可能无法由游戏原生选择器处理，此时会超时暂停并交还玩家。

## 安装

把对应平台压缩包中的 `LocalAutoPlay` 文件夹放入游戏的 `mods` 目录。PC v0.107.1 和手机 v0.111.0 的 DLL 分别编译，不可混用。无需 BaseLib 或 RitsuLib。

## 验证

PC v0.107.1 已通过 Steam 实战自动化测试：发现的原生选牌、多重释放的 X 费、指定目标攻击、三张循环连续打出、先双倍能量再考虑高费牌，以及可选弃牌的跳过逻辑。手机版 v0.111.0 已编译，尚未在手机战斗中验证；不把未测试的卡牌效果声称为已验证。
