# 局部自动出牌 v0.5.2

单人战斗中，左侧有两个操作：

- **自动一回合**：按当前局面规划出牌，必要时提前结束回合；不会接管下一回合。
- **全自动**：逐回合出牌并结束回合；开关状态保存在 `user://local_auto_play_settings.json`，下场战斗及重启游戏后继续生效，直至手动关闭。不会自动走地图、选择奖励或使用药水。

正在执行时点击「停止本回合」，会在当前牌结算后停止。全自动按钮可随时关闭。出现未知的选牌界面或游戏自身无法继续结算时，会暂停而不会强行结束回合。

## 规划与本次修复

模组读取已知抽牌顺序，并复制洗牌、产牌和随机充能球 RNG；预测不会消耗游戏的真实随机数。每张牌真实结算后重新读取状态。搜索最多 48 步、束宽 72、30,000 节点、单次 450 毫秒，不执行预览中的游戏动作。

v0.5.0 把「结束回合」纳入候选，不再为了清空手牌而强制打出无收益的防御牌或能力牌。规划器对整条路线的回合终局状态评分：计入斩杀、敌人下一次攻击、格挡、充能球被动以及下回合的球与能力价值。现已模拟球的顺序、暗球蓄能与激发、部分改造版球牌、野性回手、散热片抽牌、「搜寻」从抽牌堆选牌和「涅奥之怒」从弃牌堆回收；规划的选牌会交给游戏原生选牌界面执行。

v0.5.1 排查并修正了其他牌的同类顺序问题：充能电池和拾荒等延迟回能不再被当作当前能量，分离仅击杀后回能；原版弹幕齐射按球数计算，X 费伤害和格挡按实际 X 计算。补上全息影像、快速检索、刮削、暴风雨、回收、堆栈、万物一心、编译驱动、重启、四重释放、打碎和数种产球牌对当前回合的影响。去重状态现在区分本回合出牌数，避免超越光速的抽牌条件被误合并。每次实际出牌后仍会重新规划。

v0.5.2 根据双战斗录像补充「高蓄能黑球 + 四重释放 + 电击」顺序回归测试；规划器应先打出可斩杀的四重释放。还会等待游戏动作队列完全结算，再读取手牌；若规划期间手牌、球或敌人状态变化则重新规划。当前无可选出牌但有疑似临时不可打的卡牌时，会短暂等待状态变化，而不是立即结束回合。结束回合前记录手牌可打状态，便于后续核查录像中的实际模组版本和原因。录像中使用的模组版本无法仅凭画面确定，本次修改尚未在该手机对局实测。

单回合最多实际打出 64 张牌，以阻止零费循环。未知模组效果、附魔、随机目标与部分遗物未全部精确建模，束搜索也可能裁剪更好的顺序，因此这是限时近似最优，不保证数学意义上的全局最优。某张可打的牌如果不能改善局面，自动器可能选择留在手中并结束回合。默认不使用药水。

## 安装

把对应平台压缩包中的 `LocalAutoPlay` 文件夹放入游戏 `mods` 目录。PC v0.107.1 与手机 v0.111.0 的 DLL 分别编译，不可混用。无需 BaseLib 或 RitsuLib。
