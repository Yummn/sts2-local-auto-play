# 局部自动出牌 v0.4.0

单人战斗中点左侧「自动打牌」后，模组预测当前回合可以抽到的牌并搜索出牌顺序。每张牌仍通过游戏原生 `TryManualPlay` 真正打出；结算后会按实际局面重新规划。再次点击会在当前牌结算后停止。

## 规划范围

- 读取抽牌堆**完整已知顺序**，而不只估计能抽到几张。弃牌堆需要洗牌时，复制洗牌 RNG，在预测分支中模拟重洗；不会推进真实游戏 RNG。
- 对 Discovery、White Noise、Infernal Blade、Distraction、Jack of All Trades、Bundle of Joy、Abundance 等已识别随机产牌效果，复制产牌 RNG 预测候选卡；兼容 BetterDefect 改造版 White Noise 的三选一。原生选牌由自动选择器完成。
- 根据伤害、击杀、敌人来袭伤害、有效格挡、能力牌、充能球、回能和未来可抽牌对出牌序列评分。可先打回能牌再考虑高费牌；不限制卡牌名单，未知效果仍可尝试。
- 搜索最多 48 步、束宽 72、30,000 节点和单次 350 毫秒；每张牌结算后重新搜索。单次点击最多实际打出 64 张，以避免无限循环。不自动用药水或结束回合。

**边界：**这不是经证明的全局最优解。任意模组牌、状态触发、附魔、目标随机性和特殊选牌都可能改变未来状态；束搜索和耗时限制也会裁剪分支。随机预测仅覆盖上述已识别产牌来源。预测与实况不一致时，下一张牌会按真实状态重算。规划在后台线程运行，不执行预览中的游戏指令。

## 安装

把对应平台压缩包中的 `LocalAutoPlay` 文件夹放入游戏的 `mods` 目录。PC v0.107.1 和手机 v0.111.0 的 DLL 分别编译，不可混用。无需 BaseLib 或 RitsuLib。

## 验证

PC v0.107.1 已通过 Steam 自动化实战测试：随机发现的预测产牌与实际选牌一致、抽牌堆顶部已知牌预测并成功抽出、X 费、指定目标攻击、连续出牌、先回能后高费牌及可选弃牌跳过。手机 v0.111.0 仅通过编译，尚未在手机战斗验证。
