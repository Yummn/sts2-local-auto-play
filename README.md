# 局部自动出牌 v0.1.0

在**单人战斗**中点左侧的「自动打牌」按钮，模组会从当前手牌选择一张安全且可打出的牌，使用游戏原生 `TryManualPlay` 入队；待结算完成后重新读取局面，再选择下一张。再次点击可停止。

- 不自动结束回合、不使用药水、不替玩家处理选牌弹窗。
- 本版仅自动打出经过明确列名的普通牌；未列名或复杂模组牌留给玩家手动处理。已列名牌的改造版依然使用游戏实际效果，但评分只是近似。
- 最多连续打出 24 张，以避免零费无限循环；回合改变、界面关闭、状态不一致或出牌超时会停止。
- 不依赖 BaseLib 或 RitsuLib。兼容性以各版本实测为准。
- 局部评分考虑斩杀、敌方当前意图、缺少的格挡、伤害、抽牌、能量与费用；**不是最优解计算器**。

安装：将 `LocalAutoPlay.dll` 和 `LocalAutoPlay.json` 放在同一个 `mods/LocalAutoPlay/` 文件夹。分别使用对应游戏版本编译的包，不要混用 DLL。

## 构建与测试

Windows/Steam 安装游戏后，运行 `dotnet build LocalAutoPlay.csproj -c Release`。手机版需要用 v0.111.0 的 `sts2.dll` 等程序集作为 `Sts2DataDir` 编译。

已在 REDMI K80 Pro / 游戏 v0.111.0 验证模组加载与实战连续打出扫荡射线、循环、打击；PC v0.107.1 已编译，尚未进行实战运行验证。
