# 局部自动出牌 v0.4.1

单人战斗中，左侧有两个操作：

- **自动一回合**：自动打出本回合可用的牌，之后自动结束回合；不会接管下一回合。
- **全自动**：逐回合出牌并结束回合；开关状态保存在 `user://local_auto_play_settings.json`，下场战斗及重启游戏后继续生效，直至手动关闭。不会自动走地图、选择奖励或使用药水。

正在执行时点击「停止本回合」，会在当前牌结算后停止。全自动按钮可随时关闭。出现未知的选牌界面或游戏自身无法继续结算时，会暂停而不会强行结束回合。

## 规划与本次修复

模组读取完整已知抽牌顺序，复制洗牌与已识别产牌 RNG，在每张牌真实结算后重新规划。搜索最多 48 步、束宽 72、30,000 节点、单次 350 毫秒。对原生选牌使用自动选择器；不执行预览中的游戏动作。

v0.4.1 修复了规划器把「当前已足够的格挡」评为负分后直接停在半回合的问题：没有高分选择时仍尝试打出手中合法牌，随后自动结束回合。也修正 FTL／超越光速、Supercritical／超临界的条件抽牌预测；搜寻在能量足以支付当前手牌时降低纯回能牌的优先级。

单回合最多实际打出 64 张牌，以阻止零费循环。复杂模组效果、附魔和随机目标并未全部精确建模，束搜索也可能裁剪更好的顺序，因此不保证数学意义上的全局最优解。

## 安装

把对应平台压缩包中的 `LocalAutoPlay` 文件夹放入游戏 `mods` 目录。PC v0.107.1 与手机 v0.111.0 的 DLL 分别编译，不可混用。无需 BaseLib 或 RitsuLib。
